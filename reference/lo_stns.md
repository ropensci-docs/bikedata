# Docking stations for London, U.K.

A `data.frame` of station id values, names, and geographic coordinates
for 786 stations for London, U.K. These stations are generally (and by
default) downloaded automatically to ensure they are always up to date,
but such downloading can be disabled in the
[`store_bikedata()`](https://docs.ropensci.org/bikedata/reference/store_bikedata.md)
function by setting `latest_lo_stns = FALSE`.

## Usage

``` r
lo_stns
```

## Format

A `data.frame` of the four columns described above.
